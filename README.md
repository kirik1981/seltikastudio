# SELTIKA STUDIO

Продакшен: https://seltikastudio.ru  
Интерактивная версия (сканер на сервере): https://seltikastudio.grok.me

Этот репозиторий — статический снимок сайта для GitHub Pages.
Домен в DNS (RU-CENTER) указывает сюда, не на grok.me (у grok.me стоит noindex).

Не подключайте `seltikastudio.ru` одновременно как custom domain в Grok Build
и как GitHub Pages — сайт будет мигать новой и старой версией.
