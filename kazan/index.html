Как работаем с бизнесом Казани

  1. Собираем 10–25 вопросов, которые задают ваши клиенты («кто в Казани…», «лучшие…», «сколько стоит…»).
  2. Задаём каждый вопрос восьми системам — ChatGPT, Алиса, Perplexity, GigaChat, Gemini, Grok, Claude и DeepSeek — по 3 раза, каждый раз в новом диалоге.
  3. Отдельно считаем: процитировали (дали ссылку) и порекомендовали (назвали). Ошибка API — «нет данных», а не «не назван».
  4. Выписываем подборки и каталоги, на которые ссылаются ответы, и проверяем, есть ли там вы.
  5. Правим сайт (ответ в первом абзаце, FAQ, schema.org, llms.txt), карточки и внешние источники. Повторный замер — тем же методом.
